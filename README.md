# 一张来自10组的邀请

滚动与点击交互的邀请页面，使用 GitHub Pages 发布。

## 在线访问

https://lyhan16.github.io/invitation-animation/

## 文件

- `index.html`：完整网站，图片、样式和脚本均已内嵌。
- `.nojekyll`：直接发布静态文件。

## 更新

将新版网页替换为 `index.html`，提交并推送到 `main` 分支，GitHub Pages 会自动发布。

页面内上传图片和编辑内容仅保存在当前浏览器。如需让所有访客看到修改，请下载修改后的网页，替换仓库中的 `index.html` 后重新发布。
